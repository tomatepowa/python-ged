Identification Windows nécessaire

La GED affiche les documents selon vos droits sur les partages réseau : elle a besoin de savoir qui vous êtes. Votre navigateur aurait dû s'identifier automatiquement avec votre session Windows.

{% set hote = request.url.hostname or "" %} {% if "." in hote or ":" in hote %} {# Une adresse IP ou un nom complet est classé en zone Internet : pas d'identification automatique #}

L'adresse {{ hote }} contient des points : le navigateur la considère comme un site Internet et n'y envoie pas votre session Windows (il demande un identifiant et un mot de passe). {% if hote in ("127.0.0.1", "::1") %}Sur ce poste, utilisez plutôt {{ request.url.replace(hostname='localhost') }}. {% else %}Utilisez le nom court du serveur (sans le domaine), ou faites ajouter cette adresse aux sites « Intranet local ».{% endif %}

{% endif %}
  • Utilisez Edge ou Chrome, sur un poste connecté au domaine (ou au VPN).
  • Firefox n'envoie la session Windows qu'aux sites autorisés : dans about:config, ajoutez {{ request.url.hostname }} à network.automatic-ntlm-auth.trusted-uris.
  • Si une fenêtre vous a demandé un identifiant, saisissez votre compte Windows habituel.
  • Si cette page revient, l'adresse de la GED doit être ajoutée aux sites « Intranet local » (Options Internet › Sécurité) : demandez-le à la DSI.
