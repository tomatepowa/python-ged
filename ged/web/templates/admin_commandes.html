Commandes du serveur

← Réglages · ce qui ne se fait pas dans l'interface se lance sur le serveur, dans une console ouverte dans le dossier de la GED.

Lancer une commande

uv run ged <commande> [options]

Sur un poste installé avec Installer-Poste.ps1, le script .\outils\installation\GED-Poste.ps1 <commande> démarre PostgreSQL si besoin, puis lance la commande. uv run ged <commande> --help affiche cette aide dans la console.
