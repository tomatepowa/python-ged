GED DSI

Bienvenue sur la GED DSI

La GED vous montre les documents que vos droits Windows vous permettent d'ouvrir sur les partages réseau. Pour cela, elle vous reconnaît grâce à votre session Windows : vous n'avez aucun mot de passe à saisir, si votre navigateur est réglé pour le faire.

{% set hote = request.url.hostname or "" %} {% if firefox %}

Vous utilisez Firefox

Firefox ne transmet votre session Windows qu'aux sites qu'on lui a indiqués. Sans ce réglage, il affiche une fenêtre « Ce site vous demande de vous connecter ». À faire une seule fois :

  1. Ouvrez un nouvel onglet et tapez about:config, puis acceptez l'avertissement.
  2. Recherchez network.automatic-ntlm-auth.trusted-uris et cliquez sur le crayon.
  3. Saisissez {{ hote }} (s'il y a déjà une valeur, ajoutez ,{{ hote }} à la fin) et validez.
  4. Revenez ici et cliquez sur Se connecter.

Sans ce réglage, Firefox vous demandera votre identifiant Windows (DOMAINE\identifiant) et votre mot de passe : cela fonctionne aussi. Edge et Chrome n'ont besoin d'aucun réglage.

{% if "." in hote or ":" in hote %} {# Une adresse IP ou un nom complet est classé en zone Internet : pas d'identification automatique #}

{% endif %}
  • Utilisez Edge ou Chrome, sur un poste connecté au domaine (ou au VPN).
  • Si une fenêtre vous a demandé un identifiant, saisissez votre compte Windows habituel (DOMAINE\identifiant).
  • Si cette page revient, l'adresse de la GED doit être ajoutée aux sites « Intranet local » (Options Internet › Sécurité) : demandez-le à la DSI.
